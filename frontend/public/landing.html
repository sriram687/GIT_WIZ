Why Developers Choose GIT_WIZ

A structured, observable control layer for parallel AI coding agents.

🌳

Isolated Git Worktrees

Every agent session gets its own Git worktree directory on a dedicated branch. Run 10+ agents in parallel without file collisions or git tree dirty states.

🔄

Automated Feedback Loops

When CI checks fail or PR review comments are left on GitHub, GIT_WIZ routes error logs and reviewer feedback back to the agent session context.

💻

Live Terminal Oversight

Attach directly to any worker terminal session in real time with interactive xterm terminals, live log streams, and input permission gates.

🛠️

23+ Agent Harnesses

Works natively with Claude Code, Cursor, Codex, OpenCode, Aider, Goose, and more. Choose different agents for different projects or tasks.

📱

Mobile Companion

Pair your physical mobile device over your local network to monitor your fleet, approve terminal prompts, and triage sessions on the go.

🔒

100% Local & Private

GIT_WIZ runs as a local Go daemon on your machine. Your code, database records, and logs stay on localhost under standard Apache 2.0 open-source license.
